# Pfizer-AI-Document-Intelligence-
An object-oriented Python pipeline that turns unstructured pharmaceutical vendor documents into a searchable, question-answerable knowledge base. Documents are processed with OCR (Tesseract and PaddleOCR), indexed with LlamaIndex, and queried through a retrieval-augmented generation (RAG) workflow that returns answers with source citations. I evaluated three LLM families (Mistral, Phi-2, and OpenAI GPT) against 150+ labeled test queries, raising retrieval accuracy from 68% to 85% by tuning prompts, chunk sizes, metadata filters, and retrieval parameters. The project includes a natural-language Q&A interface for document upload and querying, and was load-tested before I presented deployment trade-offs to stakeholders.
